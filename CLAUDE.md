# Ash Project

## Commit Message Convention

All commit messages must follow this format:

```
type: description
```

**Rules:**
- Type is lowercase: `fix:`, `feat:`, `refactor:`, `style:`, `chore:`, `docs:`
- Description is concise, lowercase, no period at end
- Only the subject line — no body/description text
- Examples:
  - `fix: tool_call_id for OpenAI-compatible providers`
  - `feat: add SpawnAgentTool for dynamic subagent creation`
  - `refactor: migrate to provider/model string format`
  - `style: apply ruff formatting`
